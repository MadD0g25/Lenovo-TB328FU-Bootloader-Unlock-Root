# Publication sur GitHub

1. Extraire **TB328FU_GITHUB_PUBLIC_FR_EN.zip** : c'est le dossier public bilingue (codes sources + documentation, sans firmwares ni images patchées propres à une tablette).
2. Vérifier le contenu et lire `ATTRIBUTION_AND_LICENSES.md` avant tout dépôt public.
3. Créer un dépôt GitHub, y ajouter les fichiers ou utiliser `git init`, `git add .`, `git commit` puis lier votre dépôt.
4. **Ne pas publier** l'archive `TB328FU_COMPLETE_PRIVATE_DO_NOT_PUBLISH.zip` telle quelle : elle contient des images Lenovo/Unisoc et des images issues de l'appareil testé. Les droits et la confidentialité doivent être vérifiés.
5. Les outils tiers (`spd_dump.exe`, DLL, Magisk) doivent provenir des projets originaux ; ne pas attribuer leur code au présent projet.
6. Publier, si souhaité, un retour d'expérience sur [le ticket n°293](https://github.com/TomKing062/CVE-2022-38694_unlock_bootloader/issues/293) à l'aide des messages FR/EN dans `release/`.

**Aucune publication sur GitHub n'a été effectuée automatiquement.**
